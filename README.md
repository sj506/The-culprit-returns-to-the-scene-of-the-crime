## 컴퓨터와 자동 대전
기본 상대는 브라우저 안에서 동작하는 컴퓨터입니다. 사용자가 카드를 확정하면 컴퓨터가 자동으로 카드 선택, 질문, 확인, 교환, 최종 선택을 처리합니다. 복사·붙여넣기나 API 요금이 필요 없습니다.

컴퓨터는 `chooseComputer(view)`에 전달되는 비공개 정보가 제거된 시점만 사용합니다. 자기 손패·공개 사용 기록·조사로 얻은 단서로 가능한 상대 손패를 추정하며, 카드 수와 증언·동률 판정을 평가합니다. 실제 상대 손패나 미공개 선택에는 접근하지 않습니다. 완전한 최적 전략을 보장하지는 않습니다.

기존 저장 게임을 그대로 이어갈 수 있습니다. 대전 상대 메뉴에서 컴퓨터/ChatGPT 방식을 전환할 수 있습니다. 전환·새 게임 때 예약된 자동 행동을 취소하고, 현재 차례 토큰을 재확인해 중복 행동을 방지합니다.

## 선택 기능: ChatGPT와 플레이
ChatGPT 모드는 **채팅 전달 방식**입니다. 자동으로 ChatGPT API를 호출하거나 실시간 서버 방을 만들지 않습니다.

1. 사건 시작하기를 누르고 자신의 카드를 선택·확정합니다.
2. 상대 차례에는 '상대 차례 전달문 복사'를 눌러 ChatGPT 채팅에 붙여넣습니다.
3. ChatGPT가 답한 JSON 선택 코드를 웹에 붙여넣고 '선택 적용'을 누릅니다.
4. 필요한 조사·교환 선택을 반복하며 8라운드와 최종 선택을 진행합니다.

전달문에는 ChatGPT의 손패, 공개 기록, 능력으로 얻은 정보, 허용되는 응답 형식이 포함됩니다. 사용자의 비공개 손패와 아직 공개되지 않은 선택은 포함하지 않습니다. 전달문 자체에는 상대 손패가 있으므로 내용을 읽지 않고 복사해 공정하게 플레이해 주세요. 같은 브라우저에 모든 상태가 저장되는 친선 대전용이며, 개발자 도구를 통한 부정행위를 방지하는 서버 보안 모델은 아닙니다.

복사가 차단되면 직접 복사용 텍스트가 표시됩니다. 이전 차례 코드는 토큰 검사로 거부합니다. 잘못된 명령은 상태를 바꾸지 않습니다. 게임 중 저장소가 차단되면 화면에 안내합니다.

## 규칙
- 범인 10장 / 경찰 5장 / 증인 5장 / 시민 5장.
- 비밀 5장, 각자 손패 10장. 8라운드 동안 1장씩 동시 공개.
- 범인: 비밀 1장 확인 후 남은 손패와 선택 교환.
- 경찰: 서로 다른 상대 카드 최대 2장에 각각 직업 하나 질문. 진실 답변.
- 증인: 상대 1장 확인. 시민: 효과 없음.
- 효과는 범인 → 경찰 → 증인 순서. 같은 효과는 라운드 우선권 순서.
- 둘 다 범인이면 비밀 위치를 먼저 고른 뒤 순서대로 확인·교환. 같은 위치를 고른 뒤의 사람은 앞사람 처리 후 카드를 확인.
- 손패 위치 번호는 고정. 교환 위치의 이전 단서는 무효.
- 두 장이 남으면 직업 한 장을 남기고 나머지 한 장을 버림. 마지막 버림은 효과 없이 사용 수에 포함.
- 경찰 > 범인 > 시민 > 경찰.
- 증인 vs 다른 직업: 증인의 마지막 버림과 상대 직업이 같으면 증인 승리, 다르면 상대 승리.
- 같은 직업: 범인끼리는 시민 사용 수, 경찰·시민끼리는 범인 사용 수, 증인끼리는 경찰 사용 수 비교. 같으면 무승부.
- 최종 직업 카드와 비밀 카드는 사용 수에서 제외.

## 검증
Node.js가 있다면 다음 명령으로 재실행할 수 있습니다.

~~~sh
node test.cjs
~~~

200개 셔플 대국의 종료, 카드 수 보존, 저장·복원, 모든 직업 조합의 판정 대칭성, 증언과 동률, 범인 동시 교환, 비공개 손패/미공개 선택의 전달문 제외, 오래된 명령과 중복 질문의 거부 및 상태 복구를 검사합니다.

초기 구현 시 동일한 테스트를 JavaScript 실행 환경에서 수행했습니다: 200판, 7,458개 정상 행동, 5,076개 명시적 비교 통과. 실제 브라우저의 시각적 검수는 수행하지 않았습니다. 이 검사는 게임 밸런스나 전략의 우수성을 보장하지 않습니다.
