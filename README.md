# 범인은 현장에 다시 나타난다 — v0.4

설치·API 비용 없이 실행하는 2인 카드 게임. 기본 상대는 내장 컴퓨터이며 선택적으로 ChatGPT 턴 전달도 지원합니다.

## 새 규칙
- 경찰·범인·증인 각 6장, 총 18장. 시민 삭제.
- 전체를 섞어 각자 6장, 비밀 카드 4장, 이번 판에서 제외할 비공개 카드 2장으로 나눕니다. 제외한 두 장은 누구도 확인하거나 교환할 수 없습니다.
- 4라운드 동안 한 장씩 동시 공개. 마지막 두 장 중 한 장을 직업으로 남기고 다른 한 장은 효과 없이 버립니다.
- 경찰 > 범인 > 증인 > 경찰. 같은 직업은 무승부. 기존 증언/사용 수 비교는 폐지합니다.
- 범인: 비밀 한 장 확인 후 남은 손패와 선택 교환. 교환한 손패의 기존 단서·공개·구금이 해제됩니다.
- 경찰: 직업 하나를 수색. 상대는 그 직업이 있다면 직접 한 장을 골라 공개하며 다음 라운드에 사용할 수 없습니다. 없다면 자동으로 진실 답변합니다. 다음 라운드 종료 후 구금은 풀리지만 앞면 공개는 유지됩니다. 4라운드는 공개만 하며 최종 선택을 제한하지 않습니다.
- 증인: 상대 한 장을 직접 골라 혼자 확인합니다.
- 효과는 범인 → 경찰 → 증인. 같은 효과는 라운드마다 번갈아 갖는 우선권 순서. 둘 다 범인이면 비밀 위치부터 정하고 순서대로 확인·교환합니다. 수색 응답은 그 경찰 효과 안에서 처리됩니다.

## 실행 및 저장
index.html을 브라우저로 열거나 GitHub Pages의 main / (root)로 배포합니다. 외부 패키지·API 키가 필요 없습니다.
새 규칙 저장 키는 culprit-duel-v2입니다. 이전 culprit-duel-v1 저장은 그대로 보존하지만 규칙이 달라 이 버전으로 이어서 불러오지는 않습니다.

## 컴퓨터
컴퓨터는 자기 손패·공개 기록·조사 결과만 받는 chooseComputer(view) 함수로 선택합니다. 실제 상대 손패, 미공개 선택, 제외 카드, 미확인 비밀 카드는 받지 않습니다. 남길 직업의 상성과 조사·교환, 구금 사용 제한을 평가하는 간단한 전략이며 최적 플레이를 보장하지 않습니다.

## ChatGPT 전달 모드
대전 상대 메뉴에서 선택할 수 있습니다. 상대 차례 전달문을 채팅에 보내고 JSON 응답을 붙여넣습니다. 전달문에는 상대 손패가 포함되므로 읽지 않고 전달하는 친선 대전 방식입니다.

## 검증
node test.cjs 로 실제 HTML 안의 엔진과 컴퓨터 정책을 검사합니다.
120판, 2,878개 행동, 10,243개 검사 통과. 카드 보존, 4장 비밀·2장 제외, 구금 금지/해제/만료, 마지막 라운드 수색, 모든 승패 조합, 공개 전 선택 및 숨겨진 카드 비노출을 확인했습니다.
화면 제어 모의 실행으로 새 게임에서 자동 대전과 최종 결과·저장까지 확인했습니다. 실제 브라우저의 시각적 검수는 수행하지 않았습니다.
