      새 규칙 · 세 직업 대결

      경찰 → 범인 → 증인 → 경찰. 마지막 한 장으로 승패를 결정하며 같은 직업은 무승부입니다. 증언이나 사용 카드 수 비교는 없습니다.

      준비

      경찰·범인·증인 각 6장, 총 18장. 2장은 보지 않고 이번 판에서 제외합니다. 각자 6장씩 받고 가운데 비밀 카드 4장을 둡니다. 제외한 카드는 누구도 확인하거나 교환할 수 없습니다. 4라운드 동안 한 장씩 동시에 공개합니다. 마지막 두 장 중 직업 한 장을 남기고 나머지는 능력 없이 버립니다.

      범인 · 교환

      비밀 카드 한 장을 확인하고 원하면 손패 한 장과 교환합니다. 이번에 사용한 범인 카드는 교환할 수 없습니다. 교환된 손패의 공개 상태와 구금은 해제됩니다.

      경찰 · 수색과 구금

      직업 하나를 지정합니다. 상대는 해당 직업이 있다면 그중 한 장을 직접 골라 공개합니다. 없다면 사실대로 없다고 답하며 게임이 자동 처리합니다. 공개한 카드는 다음 라운드에 사용할 수 없고, 그 라운드가 끝나면 구금이 풀립니다. 앞면 공개는 사용하거나 교환할 때까지 유지합니다.

      다른 범인 카드를 사용해 구금된 카드를 교환하면 구금이 풀립니다. 4라운드의 경찰은 공개만 하며 최종 선택을 제한하지 않습니다.

      증인 · 확인

      상대 손패 한 장을 직접 골라 혼자 확인합니다. 손패의 위치는 고정되고 교환 시 그 위치의 기존 단서가 무효가 됩니다.

      능력 순서

      범인 → 경찰 → 증인. 같은 효과는 매 라운드 번갈아 갖는 우선권 순서로 처리합니다. 둘 다 범인이면 확인할 위치를 먼저 정합니다. 같은 비밀 위치를 골랐다면 뒤의 사람은 앞사람이 교환한 뒤 그 자리에 있는 카드를 봅니다. 수색 응답은 해당 경찰 능력 중 즉시 처리합니다.

      컴퓨터 상대

      컴퓨터는 자기 손패와 공개 기록, 조사한 정보만 사용합니다. 복사·붙여넣기와 API 요금 없이 자동 대전합니다. 대전 상대 메뉴에서 기존 ChatGPT 전달 방식도 선택할 수 있습니다.
